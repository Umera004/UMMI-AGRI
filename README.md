# 🌱 UMMI AGRI

UMMI AGRI is an advanced smart farming platform designed to help farmers manage their farms digitally.

## Features

- Farmer registration and login
- Secure password hashing
- JWT authentication
- Farmer profile management
- Crop management
- Crop status tracking
- Farm health score
- Farm statistics
- Live weather
- Weather forecast
- Agricultural marketplace
- Product listings
- Marketplace search
- Marketplace category filtering
- Edit/delete personal listings
- Responsive premium interface
- Mobile navigation
- REST API
- Security middleware
- API rate limiting
